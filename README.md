A fully working make.fun frontend made of static files: a bounty board with live prize pools and entry counts, per-bounty pages with overview, live leaderboard and rules tabs, saved bounties, and builder profile search and profiles. No build step — plain HTML, ES modules and CSS reading make.fun's public API at https://make.fun/api, with a skip link, keyboard-accessible tables and reduced-motion support.

## Run it

```sh
node --experimental-strip-types serve.ts
```

Then open http://localhost:8080. Screenshots of the live app are in `screenshots/`; `node --experimental-strip-types main.ts` writes `dossier.json` and hands in `app/` and `screenshots/` at grading.
